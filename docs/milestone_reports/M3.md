## 3. 设计决策

- 采用：自包含轻量状态图（langgraph 未装，零新依赖）；状态/迁移显式表（docs/STATE_MACHINE.md）
- 采用：快照（checkpoints 表）与事件（append-only，run 内单调 seq）分离；`EventStore.stream()` 即未来 SSE 接口
- 采用：lease + fencing token 接管；cancel 双通道（持久化标志 + 内存 token）；配置指纹不匹配默认拒恢复（CheckpointMismatchError）
