## 3. 设计决策

- 采用：数据集注册表（present/missing/unregistered 三态，缺层 skip 记原因不报错）；执行器直连各层库函数（durable 复用 scenarios 驱动）
- 采用：五指标严格口径——分母 0 返回 None；judge 仅 injectable callable，强制记录模型/prompt hash/重复次数；无 judge 显式 not_measured 禁止满分；gate 强制人审一致性字段
- 采用：gate fail-closed（基线已测本次未测→fail；完整性层 skip→fail）
- 采用：B2 臂（离线可复现）接入 verification 层；B0 HTTP 臂不接（不可观测、不可复现，注明原因）
- 未采用：把 BL-T05 真实未命中标绿（如实记 fail，runner exit 1，gate 以 gate exit 为准）
