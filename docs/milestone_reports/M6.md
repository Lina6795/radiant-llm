## 3. 设计决策

- 采用：MemoryCandidate 模式——模型只能提候选，Write Gate fail-closed（11 类机器可读拒绝原因）
- 采用：五分类（session/user_fact/decision/evidence_pointer/artifact_pointer）；evidence→user_fact 转换一律拒绝；user_fact/decision 必须显式用户确认
- 采用：supersede 不覆盖（旧值可审计、默认不召回）；显式删除真删+审计快照；TTL 只清过期 active、保留 superseded 历史
- 采用：确定性 token 重叠相关性（CJK unigram/bigram，离线可复现），非向量召回
- 未采用：embedding 召回进 Read Gate（接线时可加，但隔离/过期/superseded 过滤必须保留）
