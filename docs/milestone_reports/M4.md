## 3. 设计决策

- 采用：RRF（k=60）；Relevance+Anchor/Authority Gate；规则版 Sufficiency Grader
- 采用：reranker 只留协议 + deterministic proxy（明确标注非 cross-encoder，不下载模型）
- **结论性决策：删除 A3（proxy rerank）阶段**——实测无收益（2 变差 0 变好），gates 直接作用于 A2 输出即获全部收益；接口保留待真 cross-encoder 复测
- 未采用：dense-priority 融合做 A1（top-20 内与 A0 退化等价，改 round-robin 交错）
